# Recursos de aprendizaje (PEC5)

Para realizar la última actividad os proponemos explorar artículos de revista y congresos relacionados con el ámbito del aprendizaje automático y temas relacionados.

Os recomendamos explorar [Papers with Code](https://datascience.recursos.uoc.edu/es/papers-with-code/), un espacio donde encontraréis artículos comentados que incluyen código para reproducir experimentos, aspecto clave para poder profundizar y entender mejor el estado del arte en el ámbito del aprendizaje automático.

Por último, recordad que tenéis también la [Biblioteca](https://biblioteca.uoc.edu/es/index.html) de la UOC para realizar búsquedas de recursos de todo tipo.
