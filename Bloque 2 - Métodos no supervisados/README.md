
# 🧩 Bloque 2 — Métodos de Aprendizaje No Supervisado

## 📄 Descripción del bloque

Este bloque profundiza en los **métodos no supervisados**, un enfoque donde el modelo aprende directamente de datos no etiquetados para extraer patrones y estructuras ocultas. Se abordan algoritmos de agrupamiento y técnicas de reducción de dimensionalidad ampliamente utilizadas en la práctica profesional.

Los ejercicios permiten explorar cómo estos métodos descubren grupos naturales, afinidades o características latentes dentro de un dataset.

### 🔍 Temas principales

- Algoritmos de agrupamiento jerárquico
- Método K-means y variantes
- Agrupamiento Canopy
- Técnicas de reducción de dimensionalidad
- Aplicación práctica sobre datos no etiquetados

## 🎯 Objetivos del bloque

- Comprender los fundamentos teóricos de los métodos no supervisados.
- Conocer los parámetros clave y funcionamiento interno de los algoritmos de clustering.
- Aprender a aplicar estos métodos utilizando librerías de Python como _scikit-learn_.

## 🎓 Objetivos de la PEC2

- Aplicar múltiples algoritmos no supervisados (K-means, clustering jerárquico, DBSCAN, Mean-Shift…).
- Analizar la composición de los clústeres obtenidos.
- Identificar patrones o temáticas comunes en los datos mediante reducción de dimensionalidad y clustering.
