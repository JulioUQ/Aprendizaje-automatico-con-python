
# Recursos de aprendizaje (Bloque 3)

## Contenidos y recursos

Empezaremos este bloque con un vídeo que introduce los conceptos básicos y objetivos ligados a los métodos supervisados, seguido de la lectura de los materiales docentes propios de este bloque y un recurso adicional sobre sesgo algorítmico, problema que suele estar presente en los datos. Después, unos vídeos describen el algoritmo k-NN, las máquinas de soporte vectorial (SVM), y los árboles de decisión, una de las herramientas básicas para crear modelos supervisados.
