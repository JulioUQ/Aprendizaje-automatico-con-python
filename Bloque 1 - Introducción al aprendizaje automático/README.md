# 🧩 Bloque 1 — Preparación de Datos y Fundamentos del Proyecto de Minería de Datos

## 📄 Descripción del bloque

En este primer bloque se revisan los conceptos esenciales para iniciar un proyecto de minería de datos y se construyen los cimientos necesarios para desarrollar modelos de aprendizaje automático. El enfoque principal es la **preparación del entorno de trabajo**, la **comprensión de los datos**, y la aplicación de técnicas básicas de _data cleaning_ y reducción de dimensionalidad.

Se trabaja también con el entorno Python mediante **Anaconda** y **Jupyter Notebooks**, herramientas que se utilizarán en todas las prácticas posteriores.

### 🔍 Temas principales

- Fases y etapas de un proyecto de minería de datos
- Conceptos preliminares de estadística
- Métodos de preparación y limpieza de datos (_data cleaning_)
- Validación y evaluación de resultados
- Extracción y selección de atributos
- Reducción de dimensionalidad
- Construcción del entorno de trabajo con Python, Anaconda y Jupyter

## 🎯 Objetivos del bloque

- Comprender las fases fundamentales de un proyecto de minería de datos.
- Conocer los conceptos básicos de estadística y métricas más utilizadas.
- Aplicar técnicas de preparación, validación y evaluación de datos.
- Familiarizarse con herramientas y librerías esenciales del ecosistema Python.
- Entender y aplicar técnicas de extracción y selección de atributos.

## 🎓 Objetivos de la PEC1

- Configurar correctamente un entorno de trabajo basado en Python.
- Aplicar métodos de reducción de dimensionalidad.
- Implementar algoritmos básicos de minería de datos y evaluar resultados mediante métricas estándar.
- Manipular y visualizar datasets para comprender su estructura y distribución.
